# Campeonato_de-_futebol
Sistema de gerenciamento de campeonato de futebol desenvolvido em JavaScript com Node.js e Inquirer Prompts. Permite cadastrar, listar, atualizar e remover times, jogadores e partidas, além de calcular a classificação do campeonato com base em pontos, vitórias, empates, derrotas e saldo de gols.
